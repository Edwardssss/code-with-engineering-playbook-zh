# 关于本翻译

本站是 [microsoft/code-with-engineering-playbook](https://github.com/microsoft/code-with-engineering-playbook)（微软 ISE 工程基础手册）的**非官方社区中文翻译**。

## 原文档是什么

这是微软 ISE 团队对外公开的工程实践手册，涵盖敏捷开发、自动化测试、CI/CD、设计、安全、可观测性，以及代码评审，是一套团队级工程实践的基准。
